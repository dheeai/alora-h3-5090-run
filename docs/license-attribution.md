# Dataset access, license and attribution

- The dataset lives in the **private** HF repo `aaron1z/alora-kannada-fleurs-v1`.
  Bring your own read-scope `HF_TOKEN`; it is never committed here.
- All source recordings carried a **Creative Commons Attribution** license at collection time.
  Per-source credits, licenses and links are in the dataset repo (`metadata.jsonl`, `sources.json`,
  per-collection `ATTRIBUTION.md`).
- Clips are excerpts, re-encoded (H.264, 24 fps) with resampled audio; no endorsement implied.
- Source licenses do **not** by themselves grant permission to build identifiable voice/likeness
  models; `generation_training_ready` is false pending review.
- Do not re-publish the dataset from this repo.
